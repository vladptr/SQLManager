Зібрати будь-який запит вибором: джерела → поєднання → що показати → фільтри. Без написання SQL вручну.

Звідки брати дані?

Додайте один або кілька джерел. Назви — звичайною мовою. (Технічні імена таблиць БД лише дрібним текстом — для вас вони не обов’язкові.)

Немає потрібного джерела в списку? Його можна додати в data/schema.js (поки немає підключення до БД — каталог редагується вручну).

Як працюємо з даними?

Якщо джерел кілька — вкажіть, як їх з’єднати (які поля «одне й те саме»). Оберіть також, що зробити з результатом.

Семантичні правила

Додає статуси актуальності лише за вашим вибором; історичні записи не фільтруються автоматично.

Що має бути в таблиці-відповіді?

1. Зліва натисніть поле — воно з’явиться справа.
2. Справа оберіть, що з ним зробити (просто показати / порахувати суму / середнє / кількість…).
3. За потреби знизу вкажіть, в якому порядку показувати рядки.

Готові показники

Показники враховують зернистість і не підміняють кількість осіб кількістю рядків.

Поки порожньо — буде показано усі поля (SELECT *). Краще додати лише потрібні.

Порядок рядків (необов’язково)

Якщо не додавати — порядок буде як у базі. Якщо додати — наприклад «від більшого значення до меншого».

Які рядки залишити?

Обмеження вибірки: конкретний код, період, «поле містить…», «не порожнє» тощо. Без умов — потраплять усі рядки, що підходять за з’єднаннями.
